# AI Inspiration Notebook

每两天一期的 AI 产品灵感笔记。从 GitHub、YouTube、BuilderPulse 中筛选值得关注的 AI 产品，用产品经理视角做分析。

## 内容频道

- **AI 灵感簿** — 产品卡片式分析。每个入选项目拆解五个维度：痛点是什么、为什么用 AI 解决、产品切入视角有什么独特、这个思维还能用在哪
- **Builder Digest** — 26 位一线 AI builder 的推文实时流，AI 自动翻译为简体中文
- **Opportunities** — BuilderPulse 每日行业信号，蒸馏为普通人能看懂的语言
